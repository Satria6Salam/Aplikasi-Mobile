## 🚀 Cara Menjalankan Kode Program (*How to Run*)

Jika ingin menjalankan salah satu modul proyek di atas secara lokal:

1. **Clone Repositori Utama**
   ```bash
   git clone [https://github.com/Satria6Salam/Aplikasi-Mobile.git](https://github.com/Satria6Salam/Aplikasi-Mobile.git)
   cd Aplikasi-Mobile

```

2. **Masuk ke Folder Modul yang Diinginkan**
```bash
cd modul_1 # Sesuaikan dengan modul yang ingin dijalankan (misal: modul_1 sampai modul_10)

```


3. **Install Dependensi & Jalankan Aplikasi**
```bash
flutter pub get
flutter run

```
